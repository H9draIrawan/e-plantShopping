# e-plantShopping

An online plant shop project for discovering and shopping for plants. The app is designed to give customers a simple place to explore plant options and choose greenery for their home or garden.

## Project goals

- Make plant options easy to browse.
- Help shoppers find plants that suit their space.
- Provide a straightforward online shopping experience.

## Development

To run the project locally, follow the setup instructions for the framework and package manager used in this repository.
